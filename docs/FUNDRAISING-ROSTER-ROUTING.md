# W13: team → public roster → player fundraising

Continuation of SEC-F-001 consent work in PR36. New links use `/teams/{actual-team-id}/players/{actual-roster-player-id}`. The team page at `/teams/{actual-team-id}` lists only consented, approved, active fundraising players on that team's current roster. Other roster names, family/medical/billing details, and unapproved or withdrawn pages are not public. Baseball and softball retain actual distinct IDs even when age labels match. Demo club records never publish.

The fundraiser form gets private eligible team/player options from the verified session. A household can link only its own current roster player (household membership or verified guardian email). Coaching status alone does not grant access. Player logins cannot manage publication. Admin access requires owner grants, not a profile role claim. Existing approval/consent rules still apply; an admin editing another owner's record cannot supply that owner's consent.

Migration 0031 adds explicit team_id and roster_player_id with paired-null validation and one fundraiser per team/player. No legacy name/age matching or automatic backfill occurs. Existing page owners select the correct roster player and confirm consent through Edit. Missing links, removed roster players, absent/demo club state or revoked consent fail closed for new public player requests and new sponsorship checkout. Existing financial records/provider checkout links are retained. GET /api/fundraising/dashboard?scope=home returns no aggregate player directory; /fundraising redirects to /teams. Direct old player URLs remain compatible only for a valid linked, consented player. Generated Netlify migration copies are included; production migrations have not been executed here.

Private My fundraising and Office remain management views. Public `/teams` has links to actual team pages with public players. New share buttons use the team/player route; the player page links back to its team roster. Legacy payment receipts can still use their fundraiser reference.
