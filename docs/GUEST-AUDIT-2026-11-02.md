## Validation approach

- Isolated synthetic fixtures only; never customer accounts, production form submissions, charges or refunds.
- Timeout tests cover stalled reads, successful/error responses and rejection of late results. Shared catalog component test verifies one readiness request, SSR prices surviving failure, retry and no stale unlock.
- Existing booking, selected-athlete purchase, tryout details, roster-consent, authentication and financial regressions remain required.
- Public browser walkthrough now asserts server-rendered booking/training content, same-page tabs and the current graduation-year starting option, in addition to its existing responsive navigation, required fields, persisted synthetic request and booking checks.
- Run typecheck, build, built SSR, full regressions and the repository’s required GitHub verification job. Inspect exact Netlify preview before merge and exact production release identity after merge.
- Local managed preview could not render because its terminal.local host is rejected by Vite. No application/network protections were relaxed. Hosted preview and GitHub browser tests are the browser verification path.
